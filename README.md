# LadingContable

Landing Contable — Autónomos

Landing de conversión para estudio contable. Monotributo, asesoramiento impositivo y servicios contables para autónomos.

## Stack

- Next.js 16+
- React 19
- TypeScript
- Tailwind CSS v4

## Desarrollo

```bash
pnpm dev
```

Abrir [http://localhost:3000](http://localhost:3000)
